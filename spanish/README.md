# ¡Vamos! — تعلّم الإسبانية بالعربية

تطبيق لتعلّم الإسبانية العملية: 22 درسًا و209 كلمات وعبارات، مع صور وأصوات، وتحدّي الدقيقة، ووضع الاستماع، وقاموس.
يُثبَّت على شاشة الجوال كتطبيق، ويعمل بدون إنترنت بعد أول فتح.

## وضعه على شاشة الجوال
1. في GitHub افتح المستودع، ثم **Settings ← Pages**. تحت **Branch** اختر `main` ثم **Save**.
2. انتظر دقيقة، ثم افتح على جوالك: `https://alfjrymhmwd-blip.github.io/my-first-project/spanish/`
3. **آيفون (Safari):** زر المشاركة ⬆️ ← «إضافة إلى الشاشة الرئيسية» ← «إضافة».
   **أندرويد (Chrome):** اضغط «ثبّت التطبيق الآن» داخل التطبيق، أو القائمة ⋮ ← «تثبيت التطبيق».

ستظهر أيقونة **¡Vamos!** على شاشتك، وتفتح بلمسة كأي تطبيق.
