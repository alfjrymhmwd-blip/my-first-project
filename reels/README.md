# 🎬 النشر اليومي لحلقات الأنمي على إنستغرام (Reels)

كل يوم يعمل GitHub Actions تلقائيًا ويقوم بما يلي:
1. يأخذ **الحلقة التالية** التي لم تُنشر بعد، بالترتيب 1، 2، 3… 10، 11.
2. يدمج **مقدمة البداية + الحلقة + مقدمة النهاية** في فيديو واحد عمودي (1080×1920).
3. ينشره **Reel** على حسابك، ويسجّل الحلقة في `state.json` حتى لا تتكرر.

---

## ١) ارفع الحلقات والمقدمة والنهاية
الطريقة الأسهل، وهي تعمل من الجوال أيضًا: **إصدار (Release)** في GitHub، لأنه يقبل ملفات حتى 2GB.

1. افتح المستودع، ثم **Releases** ← **Draft a new release**.
2. في **Tag** اكتب `episodes` (بالضبط).
3. ارفع الملفات بهذه الأسماء:
   - `intro.mp4`: مقدمة البداية
   - `outro.mp4`: مقدمة النهاية
   - `001.mp4`، `002.mp4`، `003.mp4`… : الحلقات بالترتيب
4. اضغط **Publish release**. وكلما جهزت حلقات جديدة أضفها إلى الإصدار نفسه (Edit).

> الفيديوهات الأفقية (16:9) تظهر كاملة في المنتصف، وخلفها نسخة مموّهة منها تملأ الشاشة. يمكنك تغيير ذلك من `fit` في `config.json`: القيمة `pad` تضع حوافّ سوداء، والقيمة `crop` تقص الفيديو ليملأ الشاشة.

> ⚠️ أقصى طول للـ Reel عبر الـ API هو **15 دقيقة**، وهذا يشمل المقدمة والنهاية. إن كانت الحلقة أطول فقسّمها إلى أجزاء مثل `005a.mp4` و`005b.mp4`، فيُنشر كل جزء في يوم.

## ٢) جهّز حساب إنستغرام والمفتاح
1. حوّل حسابك إلى **حساب احترافي** (Creator أو Business)، واربطه بـ **صفحة فيسبوك**.
2. ادخل [developers.facebook.com](https://developers.facebook.com) ← **Create App** ← نوع **Business**، ثم أضف منتج **Instagram Graph API**.
3. استخرج **مفتاحًا دائمًا** (لا ينتهي):
   - من [business.facebook.com/settings](https://business.facebook.com/settings) ← **Users ← System users** أنشئ مستخدم نظام بصلاحية Admin.
   - امنحه صلاحية على التطبيق وعلى صفحة فيسبوك.
   - اضغط **Generate token** واختر الصلاحيات:
     `instagram_basic`، `instagram_content_publish`، `pages_show_list`، `pages_read_engagement`.
4. اعرف **رقم حساب إنستغرام** (IG User ID): افتح [Graph API Explorer](https://developers.facebook.com/tools/explorer) بالمفتاح نفسه، ونفّذ الطلب:
   `me/accounts?fields=name,instagram_business_account`
   ستجد الرقم في `instagram_business_account.id`.

## ٣) أضف الأسرار إلى المستودع
اذهب إلى **Settings ← Secrets and variables ← Actions ← New repository secret**، وأضف:
| الاسم | القيمة |
|---|---|
| `IG_USER_ID` | رقم حساب إنستغرام من الخطوة السابقة |
| `IG_ACCESS_TOKEN` | المفتاح الدائم |

> لا تضع المفتاح أبدًا داخل أي ملف في المستودع.

## ٤) جرّب ثم شغّل
- **تجربة بدون نشر**: افتح **Actions ← Daily anime Reel ← Run workflow** واترك خيار `dry_run` مفعّلًا. بعد انتهاء التشغيل حمّل الفيديو الناتج من **reel-preview** وشاهده.
- **نشر فعلي الآن**: شغّله مرة أخرى بعد إلغاء `dry_run`.
- **النشر اليومي**: يعمل تلقائيًا كل يوم الساعة **6 مساءً بتوقيت مكة** (15:00 UTC). لتغيير الوقت عدّل سطر `cron` في `.github/workflows/daily-reel.yml`.
- **نشر حلقة معيّنة**: اكتب اسم ملفها في خانة `episode` عند التشغيل اليدوي.

> النشر المجدول لا يعمل إلا من **الفرع الرئيسي** (main)، فادمج هذا الفرع أولًا.

## ٥) الوصف (الكابشن)
- القالب العام موجود في `config.json` ← `caption_template`، ويقبل هذه المتغيرات:
  `{series}` اسم المسلسل، `{n}` رقم الحلقة، `{title}` عنوانها، `{file}` اسم الملف.
- عنوان أو وصف خاص لكل حلقة تضعه في `captions.json`:
  ```json
  { "001": "عنوان الحلقة", "002": { "caption": "وصف كامل لهذه الحلقة" } }
  ```

## متابعة التقدم
`state.json` يسجّل كل حلقة نُشرت مع رابطها وتاريخها. لإعادة نشر حلقة احذف سطرها من هذا الملف، أو شغّل النشر يدويًا مع خانة `episode`.
